# NeetCode Solutions

Java solutions for problems from the [NeetCode](https://neetcode.io/) roadmap, organized topic-wise for quick revision before interviews.

## 📂 Topics Covered

| Topic | Description |
|---|---|
| [Arrays & Hashing](./Arrays%20%26%20Hashing) | Problems using arrays and hash maps/sets for fast lookups |
| [Binary Search](./Binary%20Search) | Search-space reduction problems on sorted/rotated arrays |
| [Bit Manipulation](./Bit%20Manipulation) | Problems solved using bitwise operators |
| [Linked List](./Linked%20list) | Singly/doubly linked list traversal and manipulation |
| [Math & Geometry](./Math%20%26%20Geometry) | Number theory and geometric reasoning problems |
| [Sliding Window](./Sliding%20Window) | Fixed and variable-size window problems on arrays/strings |
| [Two Pointers](./Two%20pointers) | Problems solved using the two-pointer technique |

## 🗂️ Structure

Each folder contains individual `.java` files, one per problem, named after the problem for easy reference.

## 🎯 Purpose

This repository is a personal practice log built while preparing for software developer interviews, focused on strengthening core data structures and algorithms concepts through NeetCode's curated problem list.
